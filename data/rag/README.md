# Roadmap Agent RAG 원문

Roadmap Agent가 금융 제도와 상품을 설명할 때 근거로 사용할 공식 원문을 보관합니다.

## 디렉터리 구조

- `isa/`: 개인종합자산관리계좌(ISA) 관련 법령·공식 안내
- `pension/`: 연금저축·퇴직연금(IRP) 및 ISA 만기자금 연금계좌 전환 관련 공식 안내
- `finance_tips/`: 금융감독원 금융꿀팁 API에서 선별할 교육자료(인증키 수령 후 생성)

## 저장 원칙

- 서로 다른 법령 조문과 공식 문서는 별도 파일로 저장합니다.
- 원문을 요약문으로 대체하지 않습니다.
- 법령 전체가 아니라 질의에 필요한 조문 전체를 저장합니다.
- 법령의 전체 시행일과 조문별 시행일이 다르면 조문별 시행일을 우선 기록합니다.
- 입법예고·개정안·민간 금융회사 설명은 현행 제도의 공식 원문으로 저장하지 않습니다.
- 과거 적용례·경과조치는 개정 법률번호와 시행일을 확인한 뒤 별도 문서로 저장합니다.

## 공통 메타데이터

각 문서 머리말에는 다음 값을 기록합니다.

- `source_type`
- `source_id`
- `title`
- `source_url`
- `promulgated_at`
- `effective_date`
- `collected_at`
- `section`
- `status`
