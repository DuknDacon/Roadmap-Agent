# 금융감독원 금융꿀팁 200선 API 수집기

## 준비

확인된 공식 요청 URL은 다음과 같습니다.

`https://www.fss.or.kr/fss/kr/openApi/api/tip.jsp`

필수 요청변수는 `apiType`, `startDate`, `endDate`, `authKey`이며 수집기는 JSON 응답을 사용합니다.

인증키는 코드나 문서에 저장하지 않습니다.

## 실행

저장소 루트에서 가상환경을 활성화한 뒤 실행합니다.

```bash
source .venv/bin/activate
export FSS_OPEN_API_KEY='발급받은_인증키'
python scripts/fetch_fss_finance_tips.py
```

조회 기간을 바꾸려면 다음과 같이 지정합니다.

```bash
python scripts/fetch_fss_finance_tips.py \
  --start-date 2016-01-01 \
  --end-date 2026-08-13
```

인증키 환경변수를 설정하지 않으면 터미널에서 키를 숨김 입력할 수 있습니다.

## 출력

- 전체 원문 JSON: `data/raw/금융감독원_금융꿀팁200선_YYYYMMDD.json`
- 키워드 선별 RAG 문서: `data/rag/finance_tips/*.md`

기본적으로 사회초년생의 저축·투자·ISA·연금·신용·금융사기와 관련된 문서만 RAG로 변환합니다. 전체 문서화가 필요하면 `--all`을 사용하고, 원하는 키워드는 `--keyword`를 여러 번 지정합니다.

```bash
python scripts/fetch_fss_finance_tips.py --keyword ISA --keyword 적금
```

## 최신성 주의

금융꿀팁은 게시 당시의 제도를 설명하는 자료입니다. 생성 문서에는 `status: official_source_unverified_currentness`를 기록하며, 금액·기간·자격요건은 현행 법령 또는 최신 공식 안내와 대조한 후 사용합니다.
