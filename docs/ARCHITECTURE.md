# Roadmap Agent 아키텍처 초안

## 에이전트 역할 구조

### 1. 적금 에이전트

**상위 역할:** 목표 기간 안에 가입 가능한 실제 적금상품을 비교하고 가장 안정적인 목돈 형성 경로를 제안한다.

- 입력: 월 투자 가능 금액, 목표 기간, 목표 금액, 확인된 우대조건
- 데이터: finlife 적금상품 구조화 데이터
- 계산 도구: 상품 한도, 기본·우대금리, 단리·복리, 세후 만기액, 미배정액
- 출력: 상위 실제 상품 3개 독립 비교
- 주의: 실제 상품 데이터 연결 전에는 임시 금리임을 표시

### 2. 투자 에이전트

**상위 역할:** 사용자의 위험성향과 기간에 맞는 자산군 배분 범위와 하락·기준·상승 시나리오를 설명한다.

- 입력: 위험성향 3문항, 사용자 투자비중 상한, 목표 기간
- 데이터: ISA·연금 공식 RAG, 투자위험 교육자료, 선택적 시장 요약
- 계산 도구: 투자비중 상한, 월 복리, 하락·기준·상승 범위
- 출력: 특정 상품이 아닌 현금성·채권형·주식형 자산군 비율 최대 3개
- 주의: 특정 종목·ETF·펀드를 추천하지 않고 원금손실 경고 포함

### 3. 정책상품 에이전트

**상위 역할:** 가입 가능한 자산 형성형 정책상품의 자격과 공식 혜택을 계산한다.

- 입력: 나이, 소득, 지역, 고용·재직, 중소기업, 가구·혼인 정보
- 데이터: 온통청년·중앙부처복지서비스 상세 구조화 데이터
- 계산 도구: 자격판정, 정부기여금·매칭지원금, 비과세, 중복가입 가능성
- 출력: 단일 후보 상위 3개와 가능한 최적 조합 1개
- 주의: 필수 정보가 부족하거나 가입 가능한 상품이 없으면 시나리오를 생성하지 않음

### 4. 균형 에이전트

**상위 역할:** 정책상품을 우선 검토하고 남은 월 금액을 적금과 투자 자산군에 배분한다.

- 입력: 앞선 세 에이전트의 검증된 후보와 계산값
- 계산 도구: 정책상품 우선배분, 상품한도, 위험성향별 투자 상한, 잔액 배분
- 출력: 최종 조합 1개와 대안 1개
- 주의: 정책상품·적금은 실제 상품 단위, 투자만 자산군 단위로 제시

### 5. 최종 결정권자 에이전트

**상위 역할:** 계산 함수가 정한 점수와 필수 통과조건을 보존하며 최우선 로드맵을 설명한다.

- 필수 통과조건: 가입 가능, 목표 기간 안에 만기
- 평가: 목표 달성률, 원금 안정성, 유동성, 세후 예상수익, 정책혜택
- 출력: 최우선 추천 1개와 대안 1개
- 제한: LLM은 계산값과 순위를 변경하지 않고 이유만 설명

## 공통 실행 흐름

1. 요청 검증
2. 공식 RAG 문서 검색
3. 적금·투자·정책상품·균형 시나리오 생성
4. 결정론적 계산 결과 검증
5. 최종 결정권자가 우선순위 종합
6. 근거·가정·경고와 함께 응답

## 데이터는 어디에 들어가는가

| 시나리오 | 현재 | 실데이터 연결 후 |
|---|---|---|
| 적금 에이전트 | 연 3% 임시 계산 가정 | finlife 상품별 금리·우대조건·납입방식 |
| 투자 에이전트 | 위험성향별 교육용 범위 | ISA·연금은 계좌 설명, 금융꿀팁은 위험 경고 근거 |
| 정책상품 에이전트 | 후보 없음으로 처리 | 복지·청년정책 상세의 구조화 자격판정 결과 |
| 균형 에이전트 | 적금 임시 가정 + 투자 교육 범위 | 검증된 정책·적금·투자 결과 조합 |

ISA·연금 Q&A, 투자위험 설명, RAG 검색은 별도 기능이 아니다. 투자 에이전트와 최종 결정권자가 근거 있는 설명을 만들기 위한 하위 도구다.

## LLM 연결 경계

LLM 호출은 후속 단계에서 아래 지점에만 추가합니다.

- 사용자 질문의 의도와 누락 입력 파악
- 검색 근거를 이용한 쉬운 설명
- 계산된 네 시나리오의 차이 설명

LLM 출력에서 금액·비율·순위는 계산 결과와 대조하고 불일치하면 계산 결과를 유지합니다.

## 백엔드 연결 경계

성필님 서버에는 다음 포트가 필요합니다.

- `SavingsProductRepository`: finlife 적금상품 후보 조회
- `PolicyRepository`: 나이·소득 등 구조화 조건으로 정책상품 후보 조회
- `RagRetriever`: pgvector 유사도 검색과 공식 출처 반환
- `MarketSummaryProvider`: 선택 기능인 시장 요약 반환

현재 로컬 구현은 `LocalRagRetriever`만 제공하며 나머지는 데이터 응답을 받은 뒤 인터페이스를 확정합니다.
